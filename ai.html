아트 PM 자동화 툴

art-pm-tool · 2026.10 ~ 운영 중

73개아트 공정 체크리스트
28개자동 테스트 통과
24시간NAS 상시 가동

문제 — 20명 이하 스튜디오에서 PM 1인이 전 파트와 사업관리를 겸임하면 세 가지가 반복됩니다. 요청을 자세히 안 봐서 자기 일인지 모르고, 완료 체크를 안 해서 다음 공정이 멈추고, 결국 PM이 따라다니며 챙기게 됩니다.

접근 — Kitsu(상태 저장) + Slack(알림·버튼) + git(작업물 감지)을 잇는 봇을 단계별로 만들었습니다. 배정 → 확인 → 작업물 감지 → PD 승인 → 다음 공정 자동 연결까지 A~F단계 1차 완료. 작업물 미리보기는 PNG·TGA 썸네일, PSD 레이어 합성, FBX 형태 렌더까지 구현했습니다.

남은 것 — FBX 미리보기와 실제 Unity 저장소 연동은 미확인. 회의록 자동화(H5) 1건 남음.

요괴 포커

toss-game · 토스 앱인토스 미니게임 · 개발 중

41개자동 테스트 통과
8종민화 아트
15종효과음 적용

문제 — 플랫폼 제약을 모르고 만들면 다 만든 뒤에 갈아엎게 됩니다.

접근 — 샌드박스에서 검증 가능한 범위를 먼저 확인하고 거기서 역산했습니다. 인앱 광고와 가로 모드가 테스트 불가라 세로 모드로 확정했고, 심의 경로도 미리 조사해 구글플레이의 테스터 12명×14일 요건을 피해 원스토어를 현실적 대안으로 잡았습니다. 토스 전용 기능(광고·저장·로그인)은 src/platform/ 한 곳에 모아, 스토어판에서는 그 부분만 교체하면 되게 설계했습니다.

남은 것 — 2단계 게임 코어 진행 중. 존 1 버티컬 슬라이스 작업 중.

Steam Indie Radar

steam-indie-radar · 매일 자동 수집 중

1,180개수집한 신작
276개점수 산출 완료

문제 — Steam 인기 순위는 후행 지표입니다. 거기 올라온 시점엔 이미 늦습니다.

접근 — 모멘텀·품질·화력·스트리머 적합도·숨은보석 5개 축을 분리해 점수화하고, 이미 알려진 정도는 오히려 감점으로 넣었습니다. 단순 인기순은 Steam이 이미 보여주기 때문입니다. launchd로 매일 10시 자동 수집하며 대시보드는 상시 구동합니다.

01

스코어링 편향 3건

2차 심층수집 대상을 동시접속자 내림차순으로 뽑고 있어 목적과 정반대입니다. 속도 데이터가 없는 게임 — 정확히 "아직 안 뜬 게임" — 이 구조적으로 최하위에 고정됩니다. 층화 샘플링과 순수 속도 정렬 중 미결정.

02

Unity 저장소 연동

FBX 미리보기는 공개 샘플 3종으로만 시험했습니다. 실제 프로젝트 저장소에 붙였을 때의 동작은 미확인입니다.

03

NAS 메모리

Kitsu 권장 메모리가 DS918+ 기본 사양보다 높아, 팀 전체가 쓰려면 증설이 필요할 수 있습니다.
